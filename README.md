Bird Hunting Game

A 2D arcade-style archery game built with Java Swing and AWT. Aim your bow, shoot moving birds, and avoid the bomb birds. Earn coins and spend them in the upgrade shop on stronger arrows.

Features
Three bird types with different speeds and score values, plus bomb birds to avoid
Special arrows: Thunder, Ice (freezes nearby birds), and Net
Upgrade shop to buy and improve arrows
Level progression with new backgrounds and unlockable abilities
Player profiles that save coins and high scores
Custom sound effects and background music

Tech Stack
Java, Java Swing, Java AWT, OOP, File Handling
